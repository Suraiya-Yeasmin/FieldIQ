🌍 About the Project

FieldIQ is an agricultural decision-support platform that helps farmers make smarter farming decisions using NASA Earth observation data.

Our platform provides useful insights into weather, rainfall, soil moisture, crop planning, pest risks, and sustainable agricultural strategies.

✨ Key Features

- Weather Forecast
- Farm Overview
- Field Intelligence
- Crop Library
- Pest & Disease Information
- Beneficial Insects
- Crop Calendar
- Crop Planning and Rotation
- Risk Monitoring
- FieldIQ Advisor
- Historical Analysis

🛰️ NASA Data Sources

- GPM IMERG: Precipitation data
- SMAP: Soil moisture data

🎯 Our Mission

Our mission is to make NASA Earth observation data accessible and useful for farmers, supporting informed decisions and sustainable agriculture.
